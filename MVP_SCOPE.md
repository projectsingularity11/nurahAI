# Nurah AI — Part 1 MVP

Build a web-first Expo React Native app that also runs on iOS and Android through Expo Go.

## Included in Part 1
1. Expo Router + TypeScript + NativeWind foundation
2. Dark premium Islamic UI system
3. Onboarding: name, location permission, calculation method
4. Prayer times: next prayer, full schedule, Qibla, calculation methods
5. Prayer log
6. Salah Focus mode:
   - Starts a distraction-free session
   - Optional QR/NFC prayer-mat scan
   - Manual confirmation fallback
   - Post-prayer check-in
7. Qur’an reader v1:
   - Surah list
   - Arabic + English
   - Audio player
   - Bookmarks
   - Last-read position
8. Daily authentic hadith feed
9. Dhikr counter and morning/evening adhkar
10. Basic habits/tasks
11. AI assistant v1 with strict citations and no-fatwa guardrails

## Explicitly excluded from Part 1
- Full tafsir library
- Full hadith search across all collections
- Social features
- Payments
- Native app-store publishing
- Hajj/Umrah tools
- Zakat calculator
- Community features
